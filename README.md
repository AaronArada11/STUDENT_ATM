# STUDENT ATM

A simple ATM simulation project built for practicing programming fundamentals and basic banking operations.

## Features

* Account login
* Check balance
* Deposit money
* Withdraw money
* Basic transaction handling

## Technologies

* C++
* Object-Oriented Programming

## How to Run

1. Clone the repository.
2. Open the project in your preferred C++ IDE.
3. Compile and run the program.

## Purpose

This project was created as a student project to practice programming logic, object-oriented programming, and building a simple ATM system.
