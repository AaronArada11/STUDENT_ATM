# STUDENT ATM

A simple ATM simulation project built in Java.

## Features

* Account login
* Check balance
* Deposit money
* Withdraw money
* Basic ATM transactions

## Technologies

* Java
* Object-Oriented Programming

## How to Run

1. Clone the repository.
2. Open the project in a Java IDE.
3. Compile and run the program.

## Purpose

A student project created to practice Java programming, object-oriented programming, and basic ATM system functionality.
